# v0.1.0 developer-preview checklist

## Internal release requirements

- [x] Generated TypeScript, Rust, and Python adapters build and answer through the real lab client.
- [x] HTTP/Nostr fault routing produces route-specific evidence.
- [x] Every release candidate pair is evaluated against the named 13-scenario suite.
- [x] Funded cashu-ts executes all four sender and six receiver SIGKILL/restart boundaries.
- [x] Crash controls are bearer-gated, disabled by default, and persist one-shot arms.
- [x] Sender reservations, payloads, receiver phases, and diagnostics are durable and secret-safe.
- [x] Docker build context excludes local worktrees and pnpm stores.
- [x] Redacted deterministic JSON and HTML demo artifacts are checked in.
- [x] Documentation says experimental preview and not certification.

## External certification blockers

- [ ] Integrate an independent wallet receiver maintained outside this repository.
- [ ] Obtain at least two external endorsements or maintained integrations.
- [ ] Run qualifying pairs against two distinct mint identities with trustworthy provenance.
- [ ] Publish reproducible source and build digests for release adapter images.
- [ ] Complete public-relay Nostr hardening and independent interoperability review.

Unchecked items block certification and substantial funding claims; they do not block the experimental v0.1 developer preview.
