# Cashu Fault Lab 0.1.3

Cashu Fault Lab 0.1.3 is a maintainer-preview release for wallet lifecycle recovery and local
adapter feedback. It produces reproducible developer evidence; it is not release qualification or
certification.

## What changed

- Added the wallet lifecycle lab for `mint`, `swap`, `send`, `receive`, `restore`, `reconcile`, and
  independently probed `melt` recovery.
- Runs a funded four-lane lifecycle matrix across cashu-ts and CDK against pinned Nutshell and mintd
  mints, twice from clean state.
- Exercises a real Lightning-regtest melt response-loss lane with bounded authenticated settlement
  probes and conserved NUT-08 change checks.
- Recreates and waits for CDK lifecycle host adapters during matrix rehydration, avoiding restart
  races before endpoint probing.
- Keeps adapter preflight/preview loopback-only and keeps the strict delivery release gate blocked
  until independent wallet and evidence authorities exist.

See the [v0.1.3 maintainer-preview checklist](v0.1.3-checklist.md) for completed requirements and
the external-validation blockers that remain.

## Try it

```bash
npx cashu-fault-lab@0.1.3 doctor
npx cashu-fault-lab@0.1.3 demo
npx cashu-fault-lab@0.1.3 adapter preview --adapters ./adapter-manifest.json --sender my-wallet --receiver my-wallet
```
