# Cashu Fault Lab 0.1.4

Cashu Fault Lab 0.1.4 is a maintainer-preview release for NIP-60 wallet-state diagnosis and the
existing wallet lifecycle and adapter workflows. It produces reproducible developer evidence; it is
not release qualification or certification.

## What changed

- Added the NIP-60 wallet doctor suite: multi-relay capture with NIP-44 decryption and NUT-07 mint
  verification, three-way reconstruction (per-relay, merged, mint-verified), nine stable diagnosis
  codes, and deterministic dry-run repair plans with oracle-checked safety invariants.
- Shipped `wallet-doctor collect/diagnose/plan/check/run/matrix/replay` and the versioned capture
  bundle (`spec/schemas/nip60-capture.schema.json`) as the external CI interop contract.
- Added a lab-only NIP-60 reference fixture, seven packaged scenarios, seeded replay, and the funded
  `test:doctor:funded` lane against pinned Nutshell and two fault relays.
- Extended the Nostr fault relay with persistent history partitions and authenticated HTTP fault
  control (`/v1/faults/*`, including full reset).
- Keeps adapter preflight/preview loopback-only and keeps the strict delivery release gate blocked
  until independent wallet and evidence authorities exist.

See the [v0.1.4 maintainer-preview checklist](v0.1.4-checklist.md) for completed requirements and
the external-validation blockers that remain.

## Try it

```bash
npx cashu-fault-lab@0.1.4 doctor
npx cashu-fault-lab@0.1.4 demo
npx cashu-fault-lab@0.1.4 wallet-doctor check artifacts/wallet-doctor/capture.json
npx cashu-fault-lab@0.1.4 adapter preview --adapters ./adapter-manifest.json --sender my-wallet --receiver my-wallet
```
