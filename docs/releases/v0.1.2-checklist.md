# v0.1.2 maintainer-preview checklist

## Release requirements

- [x] The npm package installs outside the monorepo on Node.js 24.
- [x] `adapter init` generates TypeScript, Rust, and Python projects with contract tests and CI.
- [x] `adapter preflight` validates manifest compatibility, loopback origins, authentication,
      capability contract, profile support, and configured read-only evidence endpoints with stable
      connectivity diagnostics.
- [x] `adapter preview` selects applicable response-loss and duplicate-delivery scenarios and
      reports unsupported capabilities as `N/A`.
- [x] The preview starts and stops its authenticated loopback fault gateway automatically.
- [x] Feedback bundles include redacted JSON, HTML, JUnit, preflight results, replay commands, and a
      maintainer README.
- [x] Retry identity, proof-state, redemption-start, and conflicting-observation failures are
      rejected.
- [x] Published runtime images and the npm package are built through GitHub Actions.
- [x] npm provenance binds v0.1.2 to the tagged source commit and publishing workflow.
- [x] Documentation describes the preview as diagnostic evidence, not certification.

## External validation blockers

- [ ] Integrate an independent wallet receiver maintained outside this repository.
- [ ] Obtain hands-on feedback from external Cashu wallet maintainers.
- [ ] Operate independent read-only ledger and mint evidence authorities for qualifying receivers.
- [ ] Run at least two qualifying implementation pairs against two distinct mint identities.
- [ ] Independently reproduce or verify source and build provenance for qualifying adapter images.
- [ ] Complete public-relay Nostr hardening and independent interoperability review.

Unchecked items do not block use of the v0.1.2 maintainer preview. They block certification and
strong interoperability or funding claims until external evidence exists.
