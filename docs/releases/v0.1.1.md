# Cashu Fault Lab 0.1.1

Cashu Fault Lab 0.1.1 is the first supported npm CLI release of the experimental v0.1 developer preview. It is not certification.

## What changed

- Preserves the `cashu-fault-lab` executable when publishing with npm 12.
- Publishes through npm Trusted Publishing with GitHub provenance.
- Uses immutable, public multi-architecture runtime images.
- Keeps the installed-package Docker demo as a release gate.

## Try it

```bash
npx cashu-fault-lab doctor
npx cashu-fault-lab demo
```

The demo runs the deterministic reference scenario locally and removes its containers and volumes afterward.

Full documentation: <https://cashu-fault-lab.vercel.app/>
